## Tech Stack
- **Framework:** React 19 + Vite 8 + TypeScript
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`) + Electric Art Studio Tokens
- **Typography:** Outfit (Display / Headings), Space Grotesk (Metrics / Technical), Plus Jakarta Sans (Body)
- **Routing:** React Router v7 (`react-router-dom`)
- **Motion & Interactions:** Framer Motion (respects `prefers-reduced-motion`)
- **Icons:** Lucide React
- **Validation:** Zod v4 (`zod`)
- **SEO & Metadata:** React Helmet Async (`react-helmet-async`), Schema.org LocalBusiness JSON-LD
